# MAYA Pinturas · Prototipo del Inicio

Demo navegable del sitio institucional de MAYA Pinturas (fabricante mexicano de pintura al mayoreo). Diseño: Nuclea Solutions.

- **Ver online:** GitHub Pages de este repositorio.
- **Ver local:** abrir `index.html` con doble clic (necesita internet para las tipografías y la cubeta 3D).

Sitio estático en HTML, CSS y JavaScript. Única dependencia externa: Three.js (CDN) para la cubeta 3D; si no carga, se muestran los mockups.

Textos e imágenes provisorios: fotos de contexto generadas con IA y datos pendientes de confirmar con el cliente.
